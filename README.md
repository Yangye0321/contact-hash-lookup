# 通讯录哈希查找系统

这是一个基于 C++ 的命令行通讯录管理程序，使用 BKDR 字符串哈希和链地址法实现联系人数据的快速查询。项目用于数据结构课程设计，覆盖哈希表、链表、字符串处理和文件持久化等内容。

## 功能

- 按姓名或电话号码建立查询哈希表。
- 添加、精确查询、模糊查询和删除联系人。
- 显示全部联系人及其查找次数。
- 统计平均查找长度（ASL）。
- 从 `contact.txt` 加载数据，并在退出或切换查询方式时保存数据。
- 使用链地址法处理哈希冲突。

联系人字段包括姓名、电话号码和地址。当前示例数据包含 40 条联系人记录。

## 技术实现

- 哈希函数：BKDRHash，种子为 131。
- 哈希表容量：53 个桶。
- 冲突处理：链地址法，每个桶使用带头结点的单链表。
- 查询关键字：姓名或电话号码。
- 数据存储：文本文件，每行保存一条联系人的姓名、电话号码和地址。
- 平均查找长度：根据节点在桶内链表中的位置进行统计。

## 编译和运行

项目使用 Visual Studio C++ 编译器 `cl.exe`。在已配置 Visual Studio C++ 开发环境的终端中执行：

```powershell
cl.exe /Zi /EHsc /nologo /Fe:HashContacts.exe HashContacts.cpp functions.cpp
./HashContacts.exe
```

也可以在 VS Code 中运行 `.vscode/tasks.json` 中的默认构建任务。程序运行时请确保当前工作目录包含 `contact.txt`，因为程序使用相对路径读取和保存数据。

## 使用流程

1. 启动程序，选择按姓名或按电话号码查询。
2. 程序读取 `contact.txt` 并建立哈希表。
3. 根据菜单编号执行查询、添加、删除、显示或平均查找长度统计。
4. 选择“更改查询方式”会先保存并清空当前哈希表，再返回查询方式选择界面。
5. 选择“退出”会保存当前数据并结束程序。

## 数据文件格式

`contact.txt` 第一行是联系人数量，后续每行依次为姓名、电话号码和地址：

```text
40
张三 13800001111 北京市海淀区中关村大街1号
```

当前读取逻辑使用空白字符分隔字段，因此地址中不能包含空格。

## 当前限制

- 菜单暂未提供独立的联系人修改功能。
- 添加联系人时，当前实现始终按姓名计算哈希地址；在电话查询模式下，新增联系人可能无法通过电话号码精确定位。
- 地址字段不能包含空格。
- 程序尚未提供独立的自动化测试目标。
