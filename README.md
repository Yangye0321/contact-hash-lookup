1、通讯录哈希查找系统 
设计内容：设计一个通讯录信息管理程序，使用散列表实现联系人快速查询，完成联系人录入、查 找、删除、修改和保存。 
核心数据结构与算法：散列表、开放定址法或链地址法、字符串处理、文件读写。 
基础要求： 
（1）联系人数据项包括姓名、电话号码、地址，可扩展邮箱或备注。 
（2）以姓名作为主关键字建立散列表，支持按姓名精确查询；可选支持按电话号码查询。 
（3）构造合理哈希函数，可采用除留余数法、BKDRHash 或类似字符串哈希方法。 
（4）采用二次探测或链地址法解决冲突，并输出冲突次数。 
（5）联系人数量不少于 30 条，统计平均查找长度，目标平均查找长度不超过 2。 
（6）支持数据保存到文件，程序重新启动后能够加载。 
扩展功能：支持模糊查询、联系人排序显示、批量导入测试数据。 
加分项：实现姓名索引与电话号码索引两个哈希表，比较不同装填因子下的查找效率。
任务：
1.完成哈希表框架----哈希函数，链地址法
2.功能------插入，查找，删除
3.写入读出文件
4.用户使用功能
5.测试
6.加入拓展功能
文档：
BKDR算法：联系人信息都为字符串
链地址法：需要进行删除修改功能
